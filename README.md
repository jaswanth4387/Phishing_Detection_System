# 🔐 Phishing Detection System

A Django-based web application that detects phishing URLs using Machine Learning with Role-Based Access Control (RBAC).

## 🚀 Features
- User Login & Registration
- URL Phishing Detection
- Provider/Admin Dashboard
- Role-Based Access Control (RBAC)
- Analytics (Charts, Ratio, Accuracy)
- ML Model Integration

## 🛠 Tech Stack
- Django
- Python
- HTML, CSS, JS
- Scikit-learn

## ▶️ Run Project

```bash
git clone https://github.com/jaswanth4387/Phishing_Detection_System.git
cd Phishing_Detection_System
pip install -r requirements.txt
python manage.py runserver
